# Product: 防詐雷達 (Anti-Scam Radar)

A Taiwanese anti-scam detection tool that helps users identify fraudulent URLs, phone numbers, and screenshots in real time.

## Core Features
- Input detection: auto-classifies user input as URL, phone number, or screenshot
- Risk analysis: returns a risk level (safe / promo / warn / scam) with a score and reasons
- Result page: two-column layout showing risk details and recommended actions (block, report, submit evidence)
- Visited page: shown when a user proceeds to a flagged scam site — provides emergency guidance
- Elder Mode (長輩模式): larger fonts, animated hints, simplified UX for older users
- TTS (Text-to-Speech): hover-to-read mode using Web Speech API
- Dark/light theme with system preference detection
- Stats page: scrollable section with 2024 Taiwan scam statistics

## Target Users
Taiwanese general public, with special consideration for elderly users.

## Language
UI and content are in Traditional Chinese (zh-TW).
